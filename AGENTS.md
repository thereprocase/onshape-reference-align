# Project instructions

## Public website design

Use the supplied Gridline design system for GitHub Pages: square panes, System Gray and white surfaces, Active Blue titles, IBM Plex Sans and Mono, visible navigation, and semantic color blocks. Use real project renders with captions. Preserve routes, downloads, viewer behavior and scientific color scales. Shared assets and maintenance notes live in https://github.com/thereprocase/thereprocase.github.io/blob/main/GRIDLINE.md.

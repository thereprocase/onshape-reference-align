Set up Onshape

Reference Align is a companion app running on this computer. This browser page is its control panel; keep the app running while you use it. Your Onshape document stays in its usual browser tab.

Connect once to place calibrated images in Onshape. You do not need to write code or set up a website. Onshape calls the connection details an API key: an access key and a secret key that you create together.

You can measure an image and preview its alignment now. Connect later from the Connection button to save it to Onshape.

1 · Create your connection key

  1. Open Onshape’s key page in a new tab. Sign in with the same Onshape account that can edit your document. The page is called the developer portal; you can use it without being a developer. Open Onshape’s API key page ↗
  2. Click API keys, then Create new API key.
  3. Tick Read documents and Write documents, then create the key. These let the app read your image and save its placement. Leave the other permissions unticked.
  4. Keep the key dialog open. Copy the access key into Access key below, then copy the matching secret key into Secret key. Onshape shows the secret key once. If you close the dialog and lose it, create a new key. These are not your Onshape email address or password.

3 · Test, then save

Test connection checks the key without changing your document. When it works, Save and continue remembers it on this computer for your next visit. Then you will paste your Part Studio link.

Press Test connection first. Nothing is written until Onshape confirms the key works.

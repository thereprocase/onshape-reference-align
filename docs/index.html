Reference Align is a local desktop companion for Onshape. Pick two pixels whose real distance you know, choose the image direction, preview, then apply. Scale and rotation can use different pairs of points.

1. Choose your computer

Download for Windows Download for Mac · Apple chip Download for Mac · Intel Download for Linux

Not sure which Mac? Choose Apple menu → About This Mac. “Chip: Apple…” means Apple chip; “Processor: Intel…” means Intel. Windows and Linux packages are for Intel/AMD 64-bit computers. These are desktop apps, not phone or tablet apps.

No programming, Node installation or web hosting needed. Everything needed to run the app comes in your download.

2. Unzip and open

Find the ZIP in Downloads. On Windows, right-click and choose Extract All. On Mac, double-click the ZIP. On Linux, use your file manager to extract it.

Inside the extracted folder, open START-HERE.html for the full guide, then start START-REFERENCE-ALIGN.cmd (Windows), START-REFERENCE-ALIGN.command (Mac), or START-REFERENCE-ALIGN.sh (Linux).

The app opens in your browser. Keep its other window open while you work. Keep all the extracted files together.

Read the step-by-step setup guide

3. Connect to Onshape and align your image

  1. Use the browser wizard to connect your Onshape account, then paste your Part Studio URL.
  2. Load an image, choose its plane, and install the calibrated reference feature.
  3. Pick your scale and direction points, preview, and apply. Writes retain backups.

For a Mac, choose Apple Silicon for M-series chips or Intel for an Intel Mac. Windows and Linux downloads target Intel/AMD 64-bit computers.

Before you launch

The app is unsigned/not notarized, so your operating system may ask whether to allow it. Only run a download from a source you trust. The included guide explains per-app prompts without disabling system security.

Connecting requires an Onshape account and a document read/write API key; the wizard explains how to create it. You can try local previews without connecting. Native Onshape Insert Image calibration is not supported; placement uses the included custom feature.

Read each release's verification notes for tested platforms and any limits. Automated tests do not replace an unaided user trial.

Independent community project; not an official Onshape product.
